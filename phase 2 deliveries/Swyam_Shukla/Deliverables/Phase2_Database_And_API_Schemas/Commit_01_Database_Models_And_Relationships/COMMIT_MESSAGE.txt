feat(database): extend SQLAlchemy models for Phase 2 logistics, disputes, and escrow

Design and extend SQLAlchemy 2.0 Declarative ORM models supporting delivery zones, shared drop points, delivery batches, canonical order status history, disputes, and financial ledger.

- Added DeliveryZone and SharedDropPoint models with PIN code array relationships.
- Added DeliveryBatch model with dual capacity (max_weight_kg, max_orders, cutoff_time).
- Extended Order model with canonical OrderStatus enum and OrderStatusHistory audit model.
- Created Dispute and DisputeEvidence models for buyer claims and photo uploads.
- Added PaymentTransaction and LedgerEntry models using integer paise currency columns.
- Verified foreign key constraints, cascade rules, and SQLite/PostgreSQL compatibility.
